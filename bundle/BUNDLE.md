# The Bundle — why two products, not one

You have two repos. They are **not** the same product and they do **not** repeat
each other. Here's the clean line between them, and how they ladder.

## One sentence each
- **Stock Stack** (`stacks` repo) = *teaches you to **make** content that doesn't
  look like AI.* A creative method. Niche-agnostic. Manual. $97.
- **Reel Engine** (`tiktok-affiliate` repo) = *an **automated system** that runs
  one money application — wellness affiliate video — end to end,* with 6 agents,
  a live Airtable backend, 4 approval gates, and TikTok/IG posting.

## Why they don't overlap (the boundary)

| Layer | Owned by | The other one… |
|-------|----------|----------------|
| **Creative method** (look consistency, prompt formula, 4-pass batch, credit discipline) | **Stock Stack** | Reel Engine *assumes* it — links to it, never re-teaches it |
| **Automation + agents** (Researcher→Scout→Director→Copywriter→Publisher→Analyst) | **Reel Engine** | Stock Stack is a manual Sunday session, no agents |
| **Affiliate pipeline + niche** (product picks, links, women's wellness) | **Reel Engine** | Stock Stack lists affiliate as *one* monetization path, generic |
| **Backend** (Airtable state machine, Base44 app, multi-tenant) | **Reel Engine** | Stock Stack is a doc, no backend |
| **Human approval gates** | **Reel Engine** | Stock Stack has none |

**The tell:** your Stock Stack's own `delivery/product-variations.md` describes
"#12 The Affiliate Content Engine… optionally bundle an agent/automation layer
that picks offers, generates the arc, and queues it." **Reel Engine is that
variation — actually built.** So this is the classic ladder: Stock Stack *teaches*
the skill; Reel Engine is the *done-for-you build* of one high-value use of it.

## Where they used to touch — now resolved
- **Posting flow:** both mentioned it. Fixed the same TikTok defect in both
  (TikTok = Higgsfield rail, never Postiz). Reel Engine owns the automated version.
- **Affiliate arc + disclosure:** Stock Stack teaches the 3-post arc and `#ad`
  rule; Reel Engine's Copywriter *automates* it and cites the Stack, not re-writes it.

Each rung solves the previous rung's next problem. Nobody buys the same thing twice.
