# Decision: one system, not two products

**We are not selling two products.** After auditing both repos, Stock Stack and
Reel Engine are **not distinct enough to sell side by side to the same buyer** —
they share the same tool spine (Higgsfield + scheduler + Claude) and both are
"content." Sold as a bundle, a method book + a machine reads as upsell padding,
which erodes the exact honesty that makes the offer convert.

**So: one product — the system you actually use.**

## What the one system is
Research → Create → Caption → Schedule → Post, run through a single pipeline,
with a human approval gate at every step. That is the whole product.

## Where the Stock Stack "method" goes
It is **not** a second SKU. The consistency method (locked look, one prompt
formula, cheap batch workflow) becomes the **quality layer inside Step 2 (Create)**
— the reason the content doesn't look AI-made. Buyers get it as part of the one
system, never as a separate purchase.

## How it's priced (same system, tiered by done-for-you)
| Tier | What's done for them | Price |
|------|----------------------|-------|
| **Do it yourself** | The full system as a blueprint + prompts + tracker template | $97 |
| **Run it in the app** | The system as software (Base44) — they approve, it runs | $79/mo |
| **Done for you** | You operate the whole system on their accounts | from $1k/mo |

These are access levels of **one** product — not different products.

## The funnel around it (yours, via ManyChat)
Top of funnel is handled *before* this page: IG post → viewer comments a keyword →
ManyChat auto-DMs the link → they land here already warm. **This page does not ask
them to comment** — that already happened. Its only job is to convert. See
`manychat-funnel.md`.

## What happens to the `stacks` repo
Keep it as your standalone creative-method asset if you ever want a separate,
niche-agnostic info product later — but it is **not** part of this offer. This
offer sells one system: the wellness content pipeline you run.
